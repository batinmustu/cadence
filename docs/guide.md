# Cadence user guide

Cadence is a local planner. Everything is stored on your computer, and it never publishes for you.

## Ideas
Type in the capture box on **Ideas** and press Enter. Pick the platforms an idea is for and add tags. The global shortcut (default ⌥Space, changeable in Settings → General) opens quick capture from anywhere.

## Drafts
Open an idea to write one variant per platform. Fields follow the platform's content type (a thread has parts, a video has a title and script). Changes save automatically. Use **Copy** to paste the text where you publish, then **Mark as published**.

## Series and calendar
A series is a recurring rhythm, such as a weekly post. Create one with **+** next to Series. Empty slots appear in the series and on the **Calendar**; assign an idea to a slot, or drag ideas onto a day. Cadence can remind you before an empty slot.

## AI help
In Settings → AI choose a provider (Anthropic, OpenAI, OpenRouter or Ollama) and store your key; it goes to the system keychain and never to the app's web view. The assistant panel in the editor offers preset commands, and series slots can be filled with AI drafts.

## Your data
Settings → Data exports everything as JSON (without API keys), imports a file into an empty library, and keeps daily database backups.
